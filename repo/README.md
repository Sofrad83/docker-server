# repo/ — vos projets

Déposez ici un dossier par site (`repo/mon-site/`, `repo/blog/`…).

Il apparaît aussitôt dans le tableau de bord (http://localhost), déjà configuré :
cliquez sur **Mettre en ligne** et ouvrez `https://mon-site.localhost`.

Le contenu de ce dossier n'est pas versionné avec docker-server (voir `.gitignore`).
